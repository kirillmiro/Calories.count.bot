# Calories-count.bot 🥗

Telegram-бот для подсчета калорий и отслеживания питания.

## Как запустить проект

1. Скачайте проект к себе на компьютер.
2. Установите зависимости:
   pip install -r requirements.txt
3. Создайте файл `config.py` в корне проекта и запишите туда:
   TOKEN = 'ВАШ_ТОКЕН_БОТА'
   DATABASE = 'Database/calories.db'
4. Запустите бота:
   cd src
   python bot.py
