
# 🥗 Calories.count.bot

**Calories.count.bot** — Telegram-бот для подсчёта калорий и отслеживания питания. Помогает вести учёт ежедневного рациона и контролировать потребление калорий.

## 🚀 Установка и запуск

### 1. Скачивание проекта

Скачайте проект или клонируйте репозиторий:

```bash
git clone <REPOSITORY_URL>
cd Calories.count.bot
```

### 2. Установка зависимостей

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `config.py` в корневой директории проекта и добавьте следующие параметры:

```python
TOKEN = 'ВАШ_ТОКЕН_БОТА'
DATABASE = 'Database/calories.db'
```

Замените `ВАШ_ТОКЕН_БОТА` на токен Telegram-бота, полученный через [@BotFather](https://t.me/BotFather).

### 4. Запуск бота

Перейдите в папку `src`:

```bash
cd src
```

Запустите бота:

```bash
python bot.py
```

## ⚙️ Используемые технологии

- Python
- Telegram Bot API
- SQLite

## 🔐 Безопасность

- Не публикуйте токен Telegram-бота в открытом доступе.
- Не загружайте файл `config.py` с реальным токеном на GitHub.
- Для хранения конфиденциальных данных рекомендуется использовать переменные окружения.

## 📌 Примечание

Перед запуском убедитесь, что все зависимости установлены, файл конфигурации заполнен правильно, а необходимые директории существуют.
